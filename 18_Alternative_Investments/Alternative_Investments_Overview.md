# Alternative Investments — Overview

Four modules: commodities, private real estate, public real estate (REITs), and hedge funds.

## Module 30 — Commodities → [[Commodities]]
Sectors & life cycle; no-cash-flow valuation & convenience yield; contango vs backwardation; theories of futures returns (normal backwardation, storage, hedging pressure); total return = spot + roll + collateral; index construction.

## Module 31 — Overview of Types of Real Estate Investment (Private/Direct) → [[Real_Estate]]
Investment features for valuation (NOI = EGI − OpEx − maintenance; LTV, DSC, equity dividend rate); economic value drivers + the **4-phase real estate cycle** (NOI/DSC/LTV over the cycle); lease types (step-up/indexed/overage); commercial property types (residential, office, industrial, retail, hospitality; GPRI); 7-element due diligence; valuation = income (direct cap value = NOI/cap rate, cap rate = r − g; DCF + terminal value NOI_n(1+g)/(r−g)), cost, sales comparison; appraisal vs transaction (repeat-sales/hedonic) indexes + appraisal-lag/unsmoothing.

## Module 32 — Publicly Traded Real Estate → [[Publicly_Traded_Real_Estate]]
REIT/REOC/mortgage REIT/MBS types; REIT structure rules (90% payout, 75% assets/income, 5/50); NAVPS via capitalized cash NOI; FFO and AFFO; four valuation approaches (NAV, P/FFO, P/AFFO, DCF); public vs private.

## Module 33 — Hedge Fund Strategies → [[Hedge_Fund_Strategies]]
Classification (equity, event-driven, relative value, opportunistic, specialist, multi-manager); return/skew profiles; conditional factor models; portfolio role.

## Cross-cutting Exam Traps
- Backwardation → positive roll return; contango → negative. Total return = spot + **roll** + collateral.
- Direct cap: value = year-1 NOI / cap rate (**cap rate = r − g**); terminal value = **NOI_n(1+g)/(r−g)**.
- DSC = NOI / debt service (interest **+ principal**); equity dividend rate = (NOI − debt service)/equity.
- Appraisal-based indexes **smooth** → understate volatility, lower correlation, **overstate** RE allocation.
- FFO = NI + D&A − gains on property sales (commonly + deferred tax); **AFFO subtracts** non-cash rent + maintenance capex. NAVPS uses **market values** (capitalize cash NOI) and beats BVPS.
- Merger arb is negatively skewed (long bond + short binary put); managed futures/global macro positively skewed (crisis alpha). Conditional factor models add a **crisis dummy** to expose hidden tail betas.
