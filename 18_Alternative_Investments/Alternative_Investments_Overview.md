# Alternative Investments — Overview

Four modules: commodities, private real estate, public real estate (REITs), and hedge funds.

## Module 30 — Commodities → [[Commodities]]
Sectors & life cycle; no-cash-flow valuation & convenience yield; contango vs backwardation; theories
of futures returns (normal backwardation, storage, hedging pressure); total return = spot + roll +
collateral; index construction.

## Module 31-32 — Real Estate (Private + REITs) → [[Real_Estate]]
Property types; income/cost/sales-comparison; direct cap (value = NOI/cap rate); appraisal vs
transaction indexes; REIT valuation via NAVPS, P/FFO, P/AFFO, DCF; FFO and AFFO definitions.

## Module 33 — Hedge Fund Strategies → [[Hedge_Fund_Strategies]]
Classification (equity, event-driven, relative value, opportunistic, specialist, multi-manager);
return/skew profiles; conditional factor models; portfolio role.

## Cross-cutting Exam Traps
- Backwardation → positive roll return; contango → negative.
- Direct cap: value = year-1 NOI / cap rate; FFO adds back depreciation, removes sale gains.
- Merger arb is negatively skewed; managed futures/global macro positively skewed (crisis alpha).
