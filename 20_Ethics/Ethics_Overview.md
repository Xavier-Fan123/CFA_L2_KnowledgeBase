# Ethical and Professional Standards — Overview

Level II ethics is **application-driven**: the Code & Standards are nearly identical to Level I, but exam items
are richer case scenarios. The grader rewards the **highest standard of conduct**. The 2026 official volume (V10)
contains **three Learning Modules**: (1) Code of Ethics & Standards of Professional Conduct, (2) Guidance for
Standards I–VII, and (3) **Application of the Code and Standards: Level II** (the seven case studies). Schweser
covers the same material as **Readings 40–42**.

## Code & Standards (LM1-2 / Schweser 40-41) → [[Code_and_Standards]]
Six components of the Code; the **seven Standards** and their subsections; the **2024 revisions** (new **I(E)
Competence**, expanded **V(B)** services-and-costs disclosure, renamed **VI(A) Avoid or Disclose Conflicts**);
high-frequency application points across all subsections; recommended compliance procedures (LOS 41.b).

## Application: Level II Cases (LM3 / Schweser 42) → [[Application_of_the_Code_and_Standards]]
The distinctive L2 reading: a **4-step decision framework** (Identify → Consider → Decide/act → Reflect) and
**seven cases** (Serengeti, Banco Libertad, QuantHouse, Jacobs Riccio, Magadi, Syyark, Agarway). First five
cases = identify violations; last two = identify **+** corrective actions **+** a firm policy statement.

## GIPS → [[GIPS]]
At L2 2026, GIPS is **not** a standalone reading — it is referenced inside **Standard III(D) Performance
Presentation** ("best method" to comply; encourage firms to adopt). The note retains the core framework:
voluntary firm-wide standards, composites, asset-weighted/time-weighted returns, disclosure, verification.

## Cross-cutting Exam Traps
- Pick the response requiring the **highest** ethical standard; follow the **stricter** of law vs Code.
- Mosaic theory is allowed; acting on material nonpublic information is not.
- **Standard I has five subsections** (A–E); don't forget **I(E) Competence**. **VI(A)** = "Avoid or Disclose."
- GIPS is **firm-wide, all-or-nothing**; composites must include all discretionary fee-paying portfolios and be **asset-weighted**.
- In a case item, name **every** applicable Standard (not just one) and, for the last two cases, give the **action + firm policy**.
